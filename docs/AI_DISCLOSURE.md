# AI disclosure

- **Development:** the code, curation scripts and documentation were written with the help of Claude (Anthropic). The team reviewed the outputs. All NASA data and quotes come from the original files and were checked by scripts, not by an AI.
- **In the app:**
  - The Scientific Copilot can use Claude (`ANTHROPIC_MODEL`, default `claude-sonnet-5-5`). It answers only from retrieved evidence. A server-side check removes any claim whose citation was not retrieved or whose numbers do not appear in the cited evidence. Without a key, the app runs in evidence-retrieval mode with no LLM, and the UI says so.
  - Semantic retrieval uses the open sentence-transformers model all-MiniLM-L6-v2.
- **Model routing:** Copilot questions are routed by fixed rules to Python (no LLM), Claude Haiku, Sonnet or Opus. The model IDs are configurable. Each answer shows the engine and model that produced it, and logs tokens, estimated cost and latency.
- **No AI-generated data:** no finding, measurement, material property or evaluation label was generated by an AI model. Burning-rate estimates come from regression on NASA FLEX data, not from an LLM.
- **Keys:** API keys live only in server environment variables and are never sent to the browser.
